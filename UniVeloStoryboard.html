UiTM Student Ride-Hailing System

UniVelo is a Grab-style smart ride-hailing platform for UiTM students, connecting passengers with nearby student drivers for fast, safe and affordable transport.

📌 System Overview

UniVelo provides three different interfaces specially designed for campus transportation management.

Admin Interface

Manage user accounts, approve student verification requests, monitor reports, and supervise the entire UniVelo ecosystem.

Passenger Interface

Passengers can request rides, track driver status, communicate with drivers, view ride history, and submit reports.

Driver Interface

Drivers can accept ride requests, set transportation fares, manage passenger rides, and update ride completion status.

🔐 Smart Registration & Verification

Every user must create an account using a username, password, and UiTM student card photo. During registration, users can choose whether they want to become a Passenger or Driver.


For safety and trust purposes, all uploaded student card photos are reviewed by the Admin before approval. The Admin can approve or reject the registration request to ensure only verified UiTM students gain access to the platform.

⚙️ UniVelo Workflow

Simple, secure, and student-friendly transportation experience.

Create Account

Students register using username, password, and student card image.

Admin Verification

Admin reviews and approves or rejects user verification requests.

Request Ride

Passenger inserts pickup and destination location while selecting car or motorcycle service.

Waiting Status

The request enters buffering mode for approximately 3–5 minutes until a driver accepts it.

Passenger & Driver Contact

Phone numbers and ride fares are displayed for easier communication.

Ride Completion

Driver presses the “Settle” button to complete the transportation service.

🛡️ Admin Features

Complete management tools for monitoring the UniVelo platform.

User Information Interface

Admin can view detailed information for all registered Drivers and Passengers within the system database.

Account Verification

Admin reviews uploaded student card photos and decides whether to approve or reject account registration requests.

User Report Management

Admin receives reports submitted by users and can investigate complaints or misconduct cases.

🙋 Passenger Features

Designed to provide a smooth and convenient ride-booking experience.

Passenger Profile

Passengers can update biodata and additional personal information for better ride management.

Ride Request

Passengers can request transportation by entering pickup and destination locations while choosing between car or motorcycle rides.

Request Status

Ride requests remain active in buffering mode for 3–5 minutes until accepted by a nearby driver.

Passenger & Driver Interface

Passengers can view driver phone numbers and transportation fees for easier communication.

Ride Completion

The transportation session ends once the driver presses the Settle button.

Ride History

Completed ride records are automatically stored for future references and tracking.

Report System

Passengers can submit reports directly to Admin regarding safety, payment, or ride issues.

🚘 Driver Features

Helping student drivers manage transportation services efficiently.

Driver Profile

Drivers can manage biodata together with detailed vehicle information such as car or motorcycle details.

Request Acceptance

Drivers may accept passenger requests and determine suitable transportation fares before the trip begins.

Driver & Passenger Interface

Drivers can view passenger phone numbers and share transportation details easily.

Trip Completion

Drivers complete the ride service by pressing the Settle button once the passenger arrives safely.

Ride History

All completed transportation sessions are stored for record and tracking purposes.

Report System

Drivers can report problematic users or ride incidents directly to the Admin management system.
